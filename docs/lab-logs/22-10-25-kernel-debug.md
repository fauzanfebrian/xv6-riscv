# Kernel Debugging

The key take points in this week is how to debug a kernel, debugging kernel is not like debugging a regular source code, debugging kernel is should use a remote debug. Debugging a kernel purpose is to get hands dirty, look directly at what happen in kernel stages.

## Tools

GNU Debugger (GDB), doing Source-Level Debugging. In this week I do deep dive into this tools `GDB` guided by Gemini to explore existing commands in `GDB`, like `b` or `breakpoints`.
